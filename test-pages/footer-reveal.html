FooterReveal Module Testing

This page tests the FooterReveal module's behavior. The footer is fixed at the bottom with a negative z-index, and the main content scrolls over it, revealing the footer underneath.

  • Reveal Effect: As you scroll down, the footer is gradually revealed from beneath the main content
  • Shadow Option: Toggle the shadow to add depth to the main content as it scrolls over the footer
  • Responsive: The module automatically adjusts the main content's margin based on the footer's height

How It Works

The FooterReveal module creates a reveal effect where the footer stays fixed at the bottom of the viewport. The main content gets a bottom margin equal to the footer's height, allowing it to scroll over the footer naturally.

This creates a sophisticated layering effect commonly seen in modern web design, where content appears to lift up and slide away to reveal what's underneath.

Configuration Options

The FooterReveal module supports these options:

  • shadow: Enable or disable the shadow effect on the main content (default: false)
  • shadowColor: Customize the shadow color (default: 'rgba(255, 255, 255, 1)')

The module automatically handles window resize events to maintain proper spacing and positioning.

Use Cases

This effect works particularly well for:

  • Landing pages with prominent calls-to-action in the footer
  • Portfolio sites showcasing contact information
  • Marketing pages with newsletter signups
  • Single-page applications with important footer content

Visual Design

The reveal effect adds depth and visual interest to your page. As users scroll, they naturally discover the footer content, which can encourage engagement with footer links, contact forms, or social media connections.

The shadow option (which you can toggle with the button above) adds an extra layer of depth, making the main content appear to float above the footer.
