StickyHeader Module Testing

This page tests the StickyHeader module's behavior in various scenarios:

  • Main Header: Stays in normal document flow and fades out when scrolled out of view
  • Auxiliary Header: A cloned fixed header that appears when the main header is not visible
  • Pin/Unpin: The auxiliary header hides on scroll down, reveals on scroll up
  • Small State: Auxiliary header shrinks after scrolling past certain threshold
  • Mobile Menu: Auxiliary header won't unpin while mobile menu is open

Watch the "Header States" indicator in the top-right corner to see the module's state changes in real-time.
