StackedBoxes Module

StackedBoxes is a layout helper that adjusts box positioning and sizing. It can "pull" elements up by a fraction of their height (1/3, 1/2, or 2/3) and match element heights dynamically.

How It Works

Each module uses data-boxes-stacked as the container.
The data-boxes-stacked-pull attribute moves elements up by the specified fraction.
Size matching keeps the left column's height synced with the right column using data-boxes-stacked-size-target and data-boxes-stacked-size-src.
